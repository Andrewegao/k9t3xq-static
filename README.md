# static image assets

Mirrored, resized product photos for the FreeRecall app (so the client never depends on a
third-party site staying up). Public-domain source images, downsized to ~1000px JPEG.
Served via jsDelivr CDN: `https://cdn.jsdelivr.net/gh/Andrewegao/k9t3xq-static@main/images/<id>-<idx>.jpg`
